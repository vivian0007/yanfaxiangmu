# 研发项目绩效自评系统 · 部署与使用说明

**访问地址：<https://vivian.jinjiazh.com>**

已部署到本服务器，架构为 **Flask 后端 + SQLite 数据库 + nginx 反向代理 + HTTPS**。
数据全部保存在**服务器本地**的 SQLite 文件里，所以**任何电脑、任何浏览器，只要用账号密码登录，就能看到自己的数据**——不再依赖浏览器本地存储，也不需要 Supabase。

| --- | --- |
| 后端程序 | `/home/ubuntu/vivian/app.py`（Flask，提供全部 REST API） |

## 角色与权限

| 角色 | 能做什么 |
| --- | --- |
| **普通研发人员** | 填自己的项目与月度进度/事项；看自己的项目、自己的月度进度。**看不到任何绩效评分** |
| **部门负责人**（新增） | 研发人员的全部功能 **＋** 查看**本部门**成员的**所有项目**与**月度绩效评分**（只读），并可导出本部门 Excel |
| **管理员** | 全部功能：用户管理、全部项目、全员月度绩效看板、部门汇总、系统设置、导出 Excel |

### 部门负责人怎么设置
1. 管理员进入「**用户管理**」，把该用户的「**部门**」填好（例如 `电子电气部`）；
2. 点该行的「**设为负责人**」按钮（或在编辑弹窗里把「部门负责人」选为"是"）。
3. 该用户重新登录后，左侧菜单会多出「**部门负责人**」分组：
   - **👥 部门成员** —— 本部门人员名单（只读）
   - **📁 部门项目** —— 本部门所有人的项目（含各月进度与本期事项，带筛选）
   - **📈 部门绩效** —— 按成员 + 年 + 月查看本部门成员的绩效评分，并可导出本部门 Excel

> **权限边界**：负责人只能看到**自己部门**的人，接口层强制校验（普通研发访问这些接口一律 403）。
> **所管部门 = 该用户自己资料里的「部门」**；若其部门为空，会提示先填写部门。

## 绩效核算权重（可修改）

绩效算法：**绩效总分 = 市场项目平均完成率 × 市场权重 ＋ 自研项目平均完成率 × 自研权重**

- 系统默认两者各 **30%**（即满分 60 分）；
- 管理员进入「**系统设置**」即可修改，页面上会**实时预览**"市场满分／自研满分 → 总分满分"；
- 保存后**所有看板、部门汇总与 Excel 导出立即按新权重计算**（历史数据无需重算，取数时动态计算）；
- 提供「恢复默认 30% / 30%」一键还原。

整体采用 **左侧菜单栏 + 右侧内容区** 的布局：点左侧菜单只显示对应模块，右侧内容随之切换，手机端菜单自动变成顶部横向滑动。
登录后会**记住你上次所在的模块**（下次登录自动回到那一页）。

     卡片间等高对齐，下方为**筛选工具条**：
     - 🔍 **关键字**：输入项目编码 / 名称 / 任务内容即时搜索；
     - **项目编码**：下拉**精确选择**某个项目编码（下拉自动去重、按字母排序）；
     - **项目类别**：全部 / 市场项目 / 自研项目；
     - **填报状态**：全部 / 本期已填报 / 本期未填报；

       每张卡片含：徽章 + 编码 + 名称 + 本期进度 + 进度条 + 「本期完成事项 / 未完成事项」填写框与操作按钮；
  4. **📅 我的项目进度** —— 「项目 × 1~12 月」进度矩阵（首列固定、当前可填报月份高亮）。

  2. **📁 部门项目** —— 本部门所有人的项目，带筛选（🔍关键字 / **项目编码** / **成员** / 类别 / 填报状态 / 排序）；

### 研发人员（登录后）
- 完善个人信息：**部门、职位**（必填）。
- 添加 / 编辑 / 删除**自己的**项目：项目编码、名称、类别（市场 / 自研）、起始时间、交付时间，以及
  **「项目任务」填写栏**（选填、可多行，例如"1. 完成硬件选型　2. 输出测试报告"，最多 2000 字）。
  - 任务栏在项目卡片上以金色竖条区块展示；管理员/部门负责人的项目大表也有「项目任务」列（鼠标悬停看全文）。
  - 项目列表的**关键字筛选也会匹配任务内容**（可按任务文字搜索项目）。
- **按月填报项目进度**（详见下方"月度进度规则"）。
- **我的项目月度进度**：主页下方以「项目 × 1~12 月」表格显示**你每个月填报的项目进度**（可切换年份回看历史月份）。
  > 研发人员**看不到任何绩效评分**（得分只有管理员能看）；后端接口同样受限，越权访问 `/api/performance*` 一律返回 **403**。
- **只能看到自己的项目**；**看不到绩效看板**（全员看板为管理员专属）。

### 月度进度规则（重要）
- 每个项目按 **(年, 月)** 记录进度，可查看某年 **1~12 月** 的逐月进度（只读历史）。
- **每月只能填报"上一个月"的进度**，其他月份**只读、禁止修改**（后端接口也会拒绝）。
  - 例：今天是 **2026-09-10** → 只能填报 **2026 年 8 月**；7 月及更早、9 月及以后都不可修改。
  - 例：今天是 **2026-01-05** → 可填报 **2025 年 12 月**。
- 项目基本信息（编码/名称/类别/日期）随时可改；**进度与事项只能通过上述规则填报**。
  - 新建项目时可顺便填一次"可填报月份"的进度与事项。
- **「本期完成事项」「未完成事项」填写框**：在「我的项目」表格中，**「本期进度」右侧新增一列**，每行有两个填写框：
  - **本期完成事项**（本期已完成的）
  - **未完成事项**（本期未完成 / 待办）
  - 填完点该行的「**保存本期事项**」即可（也可在「填进度」弹窗里和进度一起保存）。
  - 这两个框**同样只能填"上一个月"**：其他月份的接口层会被拒绝；留空保存表示清空该月事项。
  - 事项内容每项最多 2000 字，管理员在「全部项目」里同样能看到并编辑这一列。

### 管理员（`admin` 登录后）
- **用户管理**：查看全部用户；添加用户（自动初始密码 `123456`、强制首次改密）；编辑任意用户（姓名、手机号、部门、职位、**重置/设置密码**、管理员权限）；删除用户（其名下项目与月度进度**级联一并删除**）。
  - 列表**每 20 秒自动刷新**（弹窗打开时暂停），也可点「**↻ 刷新**」手动刷新——研发人员新注册的账号会自动出现。
  - 每行有「**设为管理员 / 取消管理员**」快捷按钮，可建**多个管理员账号**，它们共用同一数据库、看到的数据完全一致。
    （系统会保证至少保留 1 个管理员，且内置 `admin` 账号不可删除。）
- **全部项目**：查看所有研发人员的项目（审计），可编辑、删除纠正数据；管理员填报进度同样受"只能填上一个月"限制。
- **月度绩效看板**：选择「**人员 + 年份 + 月份**」，查看该月的：
  - 当月填报项目数
  - 市场项目平均完成率 = 该月市场项目进度之和 ÷ 该月市场项目数（无则按 0%）
  - 自研项目平均完成率 = 该月自研项目进度之和 ÷ 该月自研项目数（无则按 0%）
  - 市场项目绩效得分 = 市场平均完成率 × 30%
  - 自研项目绩效得分 = 自研平均完成率 × 30%
  - **当月绩效总分 = 市场得分 + 自研得分（满分 60 分）**
  - 下方还有**全年 12 个月逐月评分表**与**全年累计得分**，点击任意月份行可切换查看。

> 绩效按"月"分别统计：某月只统计**该月有填报进度**的项目（看板会显示项目数，便于核对）。

- **按部门筛选与汇总**：
  - 看板顶部有「**部门**」下拉，可只看某个部门的人员；
  - 下方「**部门绩效汇总**」表按当月列出：部门人数、当月已填报人数、当月平均绩效分、平均市场得分、平均自研得分、当月绩效分合计。
  - 平均绩效分 = 该部门当月"有填报"人员的当月总分之和 ÷ 当月有填报人数。
- **未填报提醒**：看板顶部会提示「**2026年8月 尚未填报的研发人员共 N 位**」并列出姓名。

> 研发人员登录后也会看到提醒横幅：「⚠️ 2026年8月 的进度还没填完：你有 N 个项目未填报」，并可点「**只看未填报**」一键筛出这些项目。

## 账号同步机制（重要）

| 场景 | 行为 |
| --- | --- |
| 研发人员新注册 | 管理后台用户列表**自动出现**（20 秒内自动刷新，或点「↻ 刷新」立即看到） |
| 管理员改了某人的姓名/手机/部门/职位 | 对方页面**每 30 秒自动同步**（无需重新登录），并弹出提示"你的账号资料已被管理员更新" |
| 管理员重置了某人的密码 | 对方在 30 秒内被要求**立即设置新密码**后才能继续使用 |
| 管理员把某人设为/取消管理员 | 对方的界面会**自动切换**为"管理后台 / 研发人员"界面 |
| 管理员删除了某人 | 对方页面会提示"账号已被删除"，并退回登录页 |
| 多个管理员账号 | 共用同一数据库，**看到的数据完全一致**，改动的资料彼此同步生效 |

> 研发人员**看不到任何绩效评分**（无论自己的还是别人的）：只能看自己每个月的**项目进度**；**绩效得分仅管理员可见**。

> 登录框的密码**默认显示明文**（不显示 `*`），方便确认输入是否正确；右侧 👁 按钮可切换隐藏。

### 通用功能（所有登录用户）
- **修改密码**：右上角导航栏点「**修改密码**」，输入**当前密码 + 新密码**即可自助修改。
  （管理员改自己密码也走这个入口；首次用初始密码登录时会被强制改密，那种情况无需输入当前密码。）
- **导出绩效 Excel**（管理员）：在「月度绩效看板」页右上角：
  - 「**导出全部绩效 Excel**」→ 导出所有研发人员；
  - 「**导出当前人员**」→ 先选中某人，再导出该人。
  - 生成的 `.xlsx` 含五个工作表：
    1. **月度绩效汇总**（指定年月的逐人数据）
    2. **全年逐月绩效**（每人 × 12 个月 + 全年累计）
    3. **项目月度进度**（含**项目任务**、**本期完成事项 / 未完成事项**）
    4. **项目任务清单**（每人 × 项目，含「项目任务」原文）
    5. **部门月度绩效**（每个部门 × 12 个月的平均绩效分与合计）

## 五、常见问题

**Q：换电脑后还要重新录入吗？**
不需要。数据存在服务器数据库里，换任何电脑登录同一账号都能看到原来录的数据。

**Q：忘记密码怎么办？**
让管理员在「用户管理」里编辑该用户、设置一个新密码即可（该用户下次登录会要求改密）。

**Q：删除用户会怎样？**
该用户及其名下所有项目会一并删除（数据库外键级联），不可恢复。

**Q：为什么注册提示"姓名已存在"？**
同一公司内姓名唯一（用于绩效统计展示）。

**Q：页面样式错乱？**
页面用了 Bootstrap 的 CDN（`cdn.jsdelivr.net`）。如果公司内网屏蔽了外网 CDN，可以告诉我，我改成把 Bootstrap 放到本服务器本地。

## 六、安全说明

- 密码使用 `werkzeug.security` 哈希存储，**不存明文**。
- 登录态基于服务器端 **session Cookie**（`HttpOnly` + `SameSite=Lax` + `Secure`）。
